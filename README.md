# INTENSE HT

STM32CubeIDE firmware project repository for **INTENSE HT**.

## Directory Layout

- `Core/Src/` : C source files
- `Core/Inc/` : Header files
- `.project`, `.cproject` : Eclipse/STM32CubeIDE project metadata

## Open with STM32CubeIDE

1. STM32CubeIDE 실행
2. **File > Import > Existing Projects into Workspace**
3. 본 저장소 루트 선택
4. `Debug` 또는 `Release` 설정 후 빌드

## Branch Policy

- `main` : 안정 기준 브랜치
- `dev` : 개발/통합 브랜치
